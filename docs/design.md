# 設計方向：潮汐表

版面與樣式的依據。對應的 DTCG token 在 [`design-tokens.json`](design-tokens.json)；`styles.css` 開頭的 CSS 變數與 token 一一對應，實作只能使用這組變數。

## 1. 概念與錨點詞

先講答案，再給理由。電價當潮汐看：低潮充電、高潮放電。首屏第一行就是「執行／等待」，理由（色帶、曲線）在下，調整（輸入、公式）再往下。

| 錨點詞 | 不是什麼 |
|---|---|
| 一眼看懂 | 不是資訊全部攤開 |
| 誠實 | 不是預測口吻 |
| 安靜 | 不是到處都是框 |

## 2. 取材對照

| 取材 | 對應決定 |
|---|---|
| 港務局潮汐表的藏青印刷字 | 主色 `color.text.primary`、襯線數字 |
| 潮汐表冷白紙 | 底色 `color.surface.page` |
| AEMO 一天 48 個 30 分鐘時段 | 招牌時刻：時段色帶 |
| 市場時間 UTC+10 與台灣時間差 2 小時 | 色帶上下兩排時間刻度 |
| 潮汐表的高潮／低潮欄 | `color.tide.low`（充電）／`color.tide.high`（放電） |

## 3. 色票

| Token | hex | 角色 |
|---|---|---|
| `color.text.primary` | `#12304F` | 內文、實際電價線、主要按鈕底、焦點框 |
| `color.text.muted` | `#4F6475` | 次要文字、輸入框邊框 |
| `color.tide.low` | `#1F6F8B` | 充電、預調度線；只用於曲線、色帶、標籤 |
| `color.tide.high` | `#9C2F55` | 放電、錯誤；只用於曲線、色帶、標籤、錯誤訊息 |
| `color.surface.page` | `#F4F7F9` | 頁面底 |
| `color.surface.raised` | `#FFFFFF` | 輸入框底、主要按鈕文字 |
| `color.band.low`／`color.band.high` | `#DCE8EE`／`#F3E1E8` | 色帶格底 |
| `color.rule` | `#C9D3DB` | 裝飾分隔線、未選中的色帶格 |

對比值（WCAG 2.x，程式計算）：

| 文字色 | page | raised | band.low | band.high |
|---|---|---|---|---|
| text.primary | 12.50 | 13.45 | 10.77 | 10.73 |
| tide.high | 6.61 | 7.12 | 5.70 | 5.67 |
| text.muted | 5.72 | 6.15 | 4.93 | 4.91 |
| tide.low | 5.27 | 5.67 | 4.54 | 4.52 |

主要按鈕白字對 `text.primary`：13.45。

禁止：`tide.low` 用於 14px 以下文字（在色帶上僅 4.52，貼門檻）；`color.rule` 對 page 只有 1.41，只能當裝飾，不能當輸入框邊框（介面元件需 ≥ 3:1，改用 `text.muted`）。「已修改」欄位不靠顏色，改用「• 已改」文字加粗邊框。

## 4. 字型

| 角色 | 字型堆疊 | 用途 |
|---|---|---|
| 中文展示 | `"Noto Serif TC", "Source Han Serif TC", "Songti TC", "PMingLiU", serif` | 「執行／等待」、區塊標題 |
| 數字展示 | `"Source Serif 4", Georgia, "Noto Serif TC", serif`，`tabular-nums` | 結果數字 |
| 內文 | `"PingFang TC", "Noto Sans TC", "Microsoft JhengHei", sans-serif` | 介面、說明 |
| 等寬 | `ui-monospace, Menlo, Consolas, monospace` | 式子、代號 |

不載入網頁字型：繁中襯線字單一字重就有數 MB，效能優先，改用作業系統內建的襯線字，沒有時退回 `serif`。字級 14／16／20／28／56（12 只用於圖表刻度、來源代號與頁尾；窄螢幕結論字改 28）；行高內文 1.6、標題 1.2。襯線只用在結論、標題與結果數字，不擴散到內文。

## 5. 版面

```
+----------------------------------------------------+
| NEM BESS 公式工作台            預調度｜情境評估     |
|----------------------------------------------------|
| 執行（56px 襯線）  價差 142 ≥ 標準 140 · 淨收益…     |
| [重新讀取 AEMO 電價] hh:mm 取得…時段、充放電區間     |
| NEM  00     03     06     09 …                     |
| ▁▁▂▂▃▃[充]▃▂▂▅▆[放 █]▇▅▃▂▁  ← 每個時段一格         |
| 台北 22     01     04     07 …                     |
| 曲線（實際＝實線、預調度＝虛線）                    |
|----------------------------------------------------|
| 輸入：電價｜設備｜判斷｜情境（分欄，無外框）        |
|----------------------------------------------------|
| ▸ 公式（預設收合，展開後每條一列，無外框）          |
+----------------------------------------------------+
```

- 間距 4／8／12／16／24／40；區塊分隔只用 24 與 40。
- 不用卡片外框與欄位分組外框，改用標題加一條 `color.rule` 分隔線。圓角只留給按鈕與輸入框（4px）。
- 色帶與曲線最小寬 600px，窄螢幕左右捲動；輸入欄自動變成單欄。
- 白話說明常駐在欄位下方小字，不只放在 hover tooltip（觸控與鍵盤使用者也看得到）。

## 6. 動態

唯一動態：結論在「等待／執行」間切換時，色帶被選中的格子 240ms 由下往上填滿（`cubic-bezier(0.2, 0.7, 0.2, 1)`）。`prefers-reduced-motion: reduce` 時直接切換。計算中不轉圈，改為結論列右側文字「計算中…」→「已更新 hh:mm」。

## 7. 招牌時刻：時段色帶

- 位置：結論列正下方、曲線上方（`src/tide_strip.js`）。
- 格數：AEMO 回應裡每個 30 分鐘時段一格（實際＋預調度），一般約一天 48 格；實際時段以較淡的格子表示。
- 實作：CSS Grid，每格一個元素，高度依這條時間軸上的電價排名分 5 級；被選中的充／放電格用 `color.band.low`／`color.band.high` 填色並加 2px 上框線。刻度每 6 格（3 小時）一個。
- 無障礙：整條為 `role="list"`，方向鍵與 Home／End 逐格移動（roving tabindex）；每格 `aria-label` 例如「NEM 14:30（台北 12:30）· 預調度 245 AUD/MWh · 放電（執行）」。
- 時段標記沿用 AEMO `SETTLEMENTDATE`（時段結束時間），頁尾明講。
- 效能：只有幾十個節點，不用 canvas、不用圖表套件。

## 8. 禁用清單

- 到處都是 1px 灰框的卡片（前一版問題）
- 單一顏色身兼多職（前一版的綠色同時代表充電、主要按鈕、分頁、已修改）
- 只能 hover 看的說明
- 轉圈動畫、漸層、雜訊紋理、交錯淡入、深色主題、三張等寬卡片首屏
- 襯線擴散到內文（黑名單「粗襯線展示字」半撞，故限縮）
