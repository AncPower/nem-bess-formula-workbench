# 設計方向：調度控制台

版面與樣式的依據。顏色與字型只用 `styles.css` 開頭的 CSS 變數；對應的 DTCG token 在 [`design-tokens.json`](design-tokens.json)。

## 概念

交易員一眼看完「電價怎麼走、何時充、何時放、值不值得做」，再往下調參數。淺底、高密度，曲線＋輸入＋結果在常見筆電螢幕（1366×768）首屏看完。

| 錨點詞 | 不是什麼 |
|---|---|
| 一眼看懂 | 不是資訊全部攤開 |
| 可操作 | 不是唯讀報表 |
| 誠實 | 不是把建議說成預測 |

取材：AEMO 調度看板的時間軸、交易台的價格走勢、電池的充／放兩種狀態。

## 版面

```
+--------------------------------------------------------------+
| 標題 · 標語                                   預調度｜情境評估 |
| [重新讀取 AEMO 電價] 取得時間、時段、充放電區間     已更新 hh:mm |
| 曲線：實際（實線）｜預調度（虛線）＋ 充電／放電色帶 ＋ 分界線  |
| 輸入：電價｜設備｜判斷與彙總｜情境假設（分組多欄）            |
| 怎麼改公式（可收合）                                          |
| 公式卡片 × N（中文算式、式子、代號對照、原則與來源）          |
| 價差標準檢討（僅情境評估）                                    |
+--------------------------------------------------------------+
```

窄螢幕：輸入與卡片改為單欄；曲線最小寬 600px，可左右捲動。

## 色票

| 名稱 | hex | 角色 | 對白底對比 |
|---|---|---|---|
| ink | `#1f2933` | 內文、實際電價線 | 14.76 |
| muted | `#52606d` | 次要文字、來源 | 6.46 |
| charge | `#0b6e4f` | 充電、執行、主要按鈕 | 6.25 |
| discharge | `#9a4600` | 放電 | 6.46 |
| forecast | `#3b5ba5` | 預調度電價線、代號、焦點框 | 6.51 |
| warn | `#b42318` | 錯誤 | 6.57 |
| paper／panel | `#f3f5f7`／`#ffffff` | 頁面底／面板底 | — |
| charge-band／discharge-band | `#e3efe9`／`#fbeedd` | 圖上色帶 | — |

所有文字色在 paper、panel 與兩種色帶上都 ≥ 4.5:1（最低 5.30，charge 對 charge-band）。主要按鈕白字對 charge 為 6.25:1。

## 字型

中文用系統字堆疊（`PingFang TC`、`Noto Sans TC`、`Microsoft JhengHei`），不載入網頁字型；代號與式子用系統等寬字。字級：12（圖表刻度）／14（介面）／16（內文、中文算式）／24（結果數字）。

## 動態

只有一個：計算中與讀取中的轉圈。`prefers-reduced-motion` 時改為靜態半透明圈。

## 招牌時刻

電價曲線上的充放電色帶：色帶上方標均價，放電標籤帶「執行／等待」，調整參數時即時更新。

## 刻意避開

漸層背景、深色主題、等寬三卡片首屏、交錯淡入動畫、圖表套件。
