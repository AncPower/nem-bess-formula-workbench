# 需求：MoSCoW 排序

三個面向共用這一張表。「適用分頁」標示需求屬於預調度、情境評估，或兩頁共用；新增需求一律加在這裡，不另開表格。

- **Must**：MVP 必備，缺一項就不算完成。
- **Should**：MVP 之後優先做。
- **Could**：有餘力再做。
- **Won't**：這個版本不做，並寫明原因。
