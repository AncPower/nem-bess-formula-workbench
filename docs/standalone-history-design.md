# T6 → P13：獨立歷史資料取得與檢討設計

狀態：設計已記錄，尚未實作與驗收。此文件不代表 T6 或 P13 完成。

## 目標與交付邊界

本 repo 可獨立從 AEMO 公開封存區下載需要的歷史資料，產生單循環每日摘要，再供 P13 價差標準檢討使用。使用者不需取得上游 GitLab 帳號、私有 Package Registry 權限，也不需 checkout 其他 repo。

T6、P13 與本資料流程置於同一分支及同一個 PR。全部完成後再建立 PR，讓同一次 PR CI 同時驗證下載器、產生器與檢討介面；若失敗，修正後仍可能需要重跑。不得沿用已合併的 T11 PR。

## 參考與來源

參考 [nem-forecast-reliability](https://git.ancillarypower.com/data/nsw-dispatch-revenue/nem-forecast-reliability) 的 `ingest/download_aemo_tables.py`：Python 標準函式庫下載 ZIP、串流讀 CSV、保留來源欄位、暫存後原子替換，以及 2024-08 前後封存檔名差異。

實際下載來源是 [AEMO MMSDM 公開封存區](https://nemweb.com.au/Data_Archive/Wholesale_Electricity/MMSDM/)，不是上游產出或私有資料套件。移植前須固定並記錄參考版本；不得把上游三張表與全部分析框架整包搬入。

## 只下載必要資料

T6 與 P13 只需要 `TRADINGPRICE`。不下載 `PREDISPATCHPRICE`、`P5MIN_REGIONSOLUTION`，也不取得因素擬合或預測誤差資料；這些不在本次交付範圍。

下載器接受明確起訖交易日、輸出目錄，來源主機固定為 AEMO。計算實際需要的封存月份時，納入末日 24:00 的次日 00:00 結算時段；本次只有結算價，不套用上游為預測資料設計的前兩日回看。

2024-07 及以前使用 `PUBLIC_DVD_TRADINGPRICE_YYYYMM010000.zip`，2024-08 起使用 `PUBLIC_ARCHIVE%23TRADINGPRICE%23FILE01%23YYYYMM010000.zip`；目錄沿用 `MMSDM_Historical_Data_SQLLoader/DATA/`。此規則來自上游程式，仍須以真實下載驗證，不能把字串產生測試當成來源可用證明。

只保留 NSW1、`INVALIDFLAG=0`、`PRICE_STATUS=FIRM` 的資料。時間使用 NEM 固定 UTC+10，不採 NSW 日光節約時間；資料時間戳是區間結束時間，00:00 屬於前一交易日。

## 來源追蹤與失敗保護

保留來源 URL、封存月份、下載時間、ZIP SHA-256、篩選後資料 SHA-256、列數與實際涵蓋期間。SHA-256 用於追溯與快取一致性，不宣稱 AEMO 提供了獨立簽章或校驗碼。

快取必須帶來源與雜湊；重用時檢查一致性。下載失敗、ZIP 損壞、CSV 表頭不合、必要欄缺漏或同一區間出現衝突價格時明確失敗，不以部分資料覆蓋先前成功版本。下載先寫暫存檔，全部必要輸入驗證後才發布新摘要。

404 不得靜默縮短指定期間：報告未發布或不存在的月份並保留舊摘要。缺資料不能變成收益零；只有完整資料但無可獲利循環，才是有效的零收益日。

## T6：可重現每日摘要

原始月檔與快取留在本機被 git 忽略的目錄；前端只讀版本化的精簡 `data/daily_summary.json`。下載與產製均能在本 repo 的命令列執行，不要求私有 Token。

5 分鐘資料依結束時刻對齊，每六筆形成 30 分鐘均價。逐日檢查預期 288 筆／48 段、重複鍵與時間間距；指定期間每一天都必須有紀錄，完全缺資料與部分缺資料都列為排除並寫明原因。

MVP 每日從空電池開始、不跨日，只選一個先充後放的完整循環。選窗與淨收益計算沿用本 repo 的設備設定與公式登記檔／共用引擎，不另建 Python 收益公式。舊 repo 的最多雙循環摘要不得冒充本次單循環結果。

每循環保存充放電開始時間、均價、價差、淨收益；每日保存有效／排除狀態、排除原因與循環陣列。摘要另存設備設定、公式與產生程式的版本／雜湊、來源 manifest、產生時間與期間統計。改設備或公式後必須重產，不可只改 metadata。

每月更新是可重跑的下載及產製流程，與 PR 審閱後發布；除非另行授權，不新增自動提交、修改標準或自動合併排程。

## P13：逐循環歷史收益保留率

情境頁讀取摘要，允許起訖日、試算標準、保留率門檻（預設 99%）、來回效率與損耗成本。試算不寫回設定檔，當期預調度資料不取代歷史資料。

逐循環計算試算收益與達標判斷，再加總已執行循環。調整效率或損耗時沿用既有窗口並重算，不宣稱已重新最佳化；必須說明這個限制。P14 前不排除特殊事件，只排除資料不完整日期。

候選標準從 0 至期間最高價差，以 1 AUD/MWh 掃描；另外直接評估非整數或高於掃描範圍的目前／試算標準。呈現執行天數、淨收益、錯失日期與收益、收益保留率、保留範圍與成本參考。無有效日或最高收益不為正時，不給門檻調整建議。

目前標準在保留範圍內為維持，高於上限為建議下調；事後價格沒有預測誤差，不產生建議上調。少於 60 個有效日提示樣本不足，只含一季提示季節限制。損益兩平價差只作說明，不限制保留範圍。

## 同一 PR 的驗證設計

單一 PR CI 工作流程同時執行：下載器的離線 HTTP／ZIP／CSV 測試、真實公開來源的小期間探測與 manifest 驗證、產製摘要、既有 Node 測試、P13 純計算與介面互動測試。公開來源探測無需任何私有 Secret；限制逾時與下載量，失敗不得顯示為完成。

完整歷史產製可能超過 CI 合理下載預算；可在具網路的本機使用同一命令執行，再將摘要與 manifest 經同一 PR 審查。必須分別記錄真實下載／產製涵蓋範圍與測試替身的範圍，不能用小樣本推稱全期間驗收。

驗證邊界包含：跨月／跨年、午夜結算、檔名切換、404、損壞 ZIP、缺欄位、非有限價格、重複與衝突、缺整天、完整零收益日、收益為零時保留率、非整數標準、逐循環而非整日全有全無，以及設定指紋不符。
